# Nife

![Nife Logo](../../logos/nife.svg)

## Overview

Internal developer platform for deploying and operating applications across public cloud, edge, Kubernetes, bare metal, and private infrastructure from one control plane.

## Key Features

- Deploys applications from Git repositories or Dockerfiles, with source-based build options.
- Targets public cloud, edge, Kubernetes, bare-metal, and private infrastructure.
- Manages applications, clusters, and virtual machines through one control plane.
- Supports multi-region application deployment and scaling.
- Provides logs, alerts, observability, and cost visibility.
- Includes AI SRE workflows for investigating and remediating operational issues.

## Getting Started

Use the Nife dashboard to configure an application from a Git repository, or use the Nife CLI after configuration:

```bash
nifectl deploy
nifectl open
nifectl regions
```

See the deployment documentation for current setup steps and required configuration.
