# Agent-QA

![Agent-QA Logo](../../logos/agent-qa.svg)

## Overview

Natural-language web and mobile application testing with execution memory, a CLI, dashboard, and MCP tools.

## Key Features

- Describe web, Android, and iOS test journeys in natural language.
- Reuse execution memory and recover from UI changes during later runs.
- Inspect run artifacts and failures through the dashboard or MCP tools.

## Getting Started

Requires Node.js 24 or newer, or Bun. Install the CLI in your project:

```sh
npm install -D agent-qa
```

Follow the official quickstart to initialize a workspace, configure a model and browser or mobile runtime, and run your first test. Agent QA is source-available under FSL-1.1-ALv2. There is no software fee for permitted use; configured model, browser, and device providers may charge separately.
