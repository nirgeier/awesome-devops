# KnoxOps

![KnoxOps Logo](../logos/knoxops.svg)

## Overview

AI-native ops agent that gives AI agents production-safe execution with human review and a built-in knowledge graph.

## Key Features

- Production execution for AI agents within safety guardrails
- Human review required for every production change
- Plan-first workflows with AI reviewing each stage
- Built-in knowledge graph of production infrastructure
