# Peon

## Overview

Open-source self-hosted Docker PaaS for deploying Git apps, Docker Compose stacks, databases, and static sites on your own servers.

## Key Features

- Project-level RBAC and audit logs
- Git, Docker Compose, database, and static site deployments
- MCP server for AI agent deployments
- Open-source MIT alternative to Vercel/Heroku/Coolify

## Getting Started

See the [installation docs](https://peon.sh/docs/installation) and Docker Compose quick start on GitHub.
